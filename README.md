# RandomNameMaker

文字種や国風などを指定して、ランダムな名前・文字列を作るブラウザ用ツール。4コマ漫画の話を考えるためのネタ出しモードも付ける。

## 欲しい機能

- 平仮名・片仮名・数字・漢字・アルファベット
- 苗字と名前で分けられる
- その国風みたいな要素が欲しい
- 文字数制限なし
- 文字列をいくつ生成するか
- 濁音・半濁音・小文字
- 発音できない文字列を出さない設定
- 使われやすい文字は出やすくする設定
- 意味のある言葉からランダムのモード
- 4コマ漫画のような話を考えるモード
    - 話を考えやすいような設定などをランダムで出して誘導するような感じ

## 構成（決定事項）

- 技術: Vite + TypeScript（フレームワークなし）、テストは Vitest、静的サイトとして公開
- 国風: 日本・英米・中華・独・仏・北欧・ファンタジー
- 進め方: 4モードをまとめて作ってから確認する

### モード
1. 文字列モード: 文字種（ひらがな/カタカナ/漢字/英大/英小/数字）、濁音・半濁音・小文字のON/OFF、文字数（最小〜最大、上限なし）、生成数、発音できる文字列だけ（かなはモーラ単位、英字は子音＋母音で組み立てる）、出現頻度の重み付け
2. 名前モード: 苗字/名前/両方、国風、性別、「実在の名前から選ぶ」か「それっぽく作る」か（日本・中華は漢字パーツの組み合わせ、欧米・ファンタジーは名前リストから学習したマルコフ連鎖）
3. 単語モード: カテゴリ別の単語辞書から組み合わせる（形容詞＋名詞、名詞の名詞 など）
4. 4コマネタモード: 人物（名前・性格・立場・口ぐせ）、関係性、舞台、季節、小道具、起承転結のお題、オチのタイプ。項目ごとに固定と引き直しができる
- 共通: コピー、お気に入り（localStorage）、シード値の指定

### ディレクトリ
```
src/

tests/
```
