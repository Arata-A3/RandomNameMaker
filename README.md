# RandomNameMaker

文字種や国風などを指定して、ランダムな名前・文字列を作るブラウザ用ツール。4コマ漫画の話を考えるためのネタ出しモードも付ける。

## 欲しい機能

- 平仮名・片仮名・数字・漢字・アルファベット
- 苗字と名前で分けられる
- その国風みたいな要素が欲しい
- 文字数制限なし
- 文字列をいくつ生成するか
- 濁音・半濁音・小文字
- 発音できない文字列を出さない設定
- 使われやすい文字は出やすくする設定
- 意味のある言葉からランダムのモード
- 4コマ漫画のような話を考えるモード
    - 話を考えやすいような設定などをランダムで出して誘導するような感じ
